# 孟德尔遗传定律 · 一轮复习（3D 交互课件）

深圳实验学校高三生物 · 单屏不滚动 · Three.js 3D 课件。

## 在线打开

GitHub Pages 发布后地址：

https://changinglu92.github.io/mendel-laws-3d/

## 本地打开

用浏览器直接打开 `index.html`，或：

```bash
python3 -m http.server 8877
```

再访问 http://127.0.0.1:8877/

## 内容

| 模块 | 课本例子 |
|------|----------|
| 分离定律 | 豌豆高茎 / 矮茎（Dd）· 减数分裂配子形成 |
| 自由组合定律 | 豌豆黄圆 / 绿皱（YyRr）· 两种赤道板取向 → 1∶1∶1∶1 |

## 课堂操作

- 首页两卡「开始讲解」
- ← → / 空格：步进
- Esc：回首页
- 拖拽旋转 3D；自由组合按 1 / 2 切换取向
- F11 全屏投影

## 说明

染色体为示意级 3D，便于讲「等位基因随同源染色体在减Ⅰ分离」。
