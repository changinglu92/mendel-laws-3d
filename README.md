# 孟德尔遗传定律 · 一轮复习（3D）

深圳实验学校高三生物投影课件。人教版必修2《遗传与进化》第1章第1节为主线。

## 模块

1. **基因的分离定律（豌豆高茎/矮茎 Dd）**
   - 课本故事线：杂交 → F₂ 3∶1 → 假说 → 测交验证 → 定律表述
   - 细胞学实质：减Ⅰ后期等位基因随同源染色体分离（Three.js）
   - 要点补强：假说 vs 演绎、适用范围（核基因 / 质基因）、自交 ≠ 自由交配
   - 特例入门：不完全显性（F₂ 1∶2∶1）、显性纯合致死（2∶1）
   - 做中学：测交、基因型反推、配子比例、特例辨析（即时反馈）

2. **基因的自由组合定律（YyRr）**
   - 课本故事线：黄圆×绿皱 → 9∶3∶3∶1 → 假说 → 测交 1∶1∶1∶1 → 定律与前提
   - 细胞学实质：减Ⅰ两种赤道板取向 → 四种配子 1∶1∶1∶1（Three.js）
   - 拆分法：(3∶1)×(3∶1)；多对独立遗传连乘
   - 特殊分离比入门：9∶3∶4 / 15∶1 / 9∶6∶1
   - 做中学：测交、黄皱 3/16、连乘、特殊比（即时反馈）

## 使用

打开 `index.html`，或访问 GitHub Pages：

https://changinglu92.github.io/mendel-laws-3d/

操作：大按钮「下一步 / 上一步」、步骤圆点、← →、Esc 回首页。单屏无滚动投影友好。
